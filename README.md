# Commonplace

A simple collection of standalone HTML pages. Open `index.html` to browse the
collection.

## Add a page

1. Create an HTML file in `entries/`.
2. Give the page a descriptive `<title>` and heading, then add its content and
   tags.
3. Add a link to the page in the list in `index.html`, with the page title and
   its tags.

The index is a static HTML file, so new pages must be added to its list.
